`ddl/bronze/` (implying `ddl/silver/`/`ddl/gold/`). LLD v1.24 (§intro / §9.1 /

one-shot `_infra/docker/ddl-apply.sh` / `make ddl-apply` (dated + zero-padded
prefix gives bronze → silver → gold order; no per-layer subdirs).
