# Product Requirements Document: Docker Development Environment

## Overview
Create a Docker-based development environment for the Redefining Data Engineering with AI project that includes all necessary tools and dependencies for data engineering workflows.

## Requirements

### Base Image Requirements
- Python 3.11
- Java 11

### Python Packages
- pytest (testing framework)
- pyenv (Python version management)
- pyspark 4.x (Apache Spark for Python)
- sqlmesh (SQL transformation framework)
- duckdb (embedded analytical database)
- GCP SDK/libraries (Google Cloud Platform integration)
- Apache Superset (data visualization and BI platform)

### Development Tools
- Cursor (AI-powered code editor)
- Claude Code (AI coding assistant)

### Infrastructure
- Docker Compose configuration for multi-container orchestration
- Single unified Docker image containing all dependencies

## Technical Specifications

### Docker Image
- Base: Official Python 3.11 image
- Additional runtime: OpenJDK 11
- All Python packages installed via pip with pinned versions
- Properly configured environment variables for tools
- Volume mounts for project code and data
- Exposed ports for Superset and any other web services

### Docker Compose
- Service definitions for the development environment
- Persistent volume configurations
- Network configurations for inter-service communication
- Environment variable management
- Health checks for services

## Deliverables

1. Dockerfile with Python 3.11 and Java 11 base
2. requirements.txt with all specified Python packages
3. docker-compose.yml for service orchestration
4. Documentation for building and running the environment
5. Scripts for common development tasks (if needed)

## Success Criteria

- Docker image builds successfully without errors
- All specified packages are installed and functional
- Docker Compose can spin up the environment
- Developers can run PySpark jobs
- SQLMesh can execute transformations
- DuckDB is accessible for queries
- Superset UI is accessible via browser
- GCP SDK is configured and functional
- Development tools (Cursor, Claude Code) can connect to the environment

## Constraints

- Image size should be optimized where possible
- Build time should be reasonable (consider layer caching)
- Must work on macOS, Linux, and Windows (via Docker Desktop)
- Should follow Docker best practices for security and efficiency
