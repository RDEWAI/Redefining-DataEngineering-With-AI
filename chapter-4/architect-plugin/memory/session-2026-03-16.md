2. **SCD Strategy**: SCD Type 2 with versioned rows on 4 dimension tables (patients, providers, payers, organizations). Team proficient with Delta MERGE INTO.
3. **Gold Tables**: 3 consumer-aligned tables (patient_summary, patient_clinical_history, patient_billing_summary) to enforce data visibility rules [DRD SS5.5].
4. **Growth**: Low 5-10% annual growth. Stable patient population.
5. **DR**: Relaxed RTO 4h / RPO 24h. Read-only system rebuildable from source.
6. **Monitoring**: Spark Expectations + Marquez + Grafana. Note: Grafana is NOT in the current technology catalog -- requires catalog update.
