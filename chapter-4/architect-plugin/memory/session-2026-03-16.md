## Architecture Pattern Selected
- **Medallion (Bronze/Silver/Gold)** with batch processing
- Justification: Team proficient, DRD SLAs satisfied (1hr clinical, 24hr billing), no streaming requirement at query level, infrastructure is local Docker only

## Key Design Decisions
1. **Medallion over Lambda/Kappa/Data Vault** -- team has no streaming experience; DRD requires 1hr max latency, not sub-minute
2. **Delta Lake** -- mandated by infrastructure constraints; team proficient
3. **Unity Catalog OSS** -- in approved tech catalog; catalog name = `spark_catalog`
4. **SCD Type 2** for 4 dimension tables (patients, providers, payers, organizations)
5. **Full Snapshot CDC** for all 13 tables -- no `updated_at` columns in source (verified via DB query)
6. **3 Gold tables** -- patient_summary (clinical), patient_clinical_history (timeline), patient_billing_summary (finance)
7. **Hourly batch** for medications and allergies (Phase 1 compromise vs DRD sub-minute sync)
8. **4h RTO / 24h RPO** for Phase 1 (read-only system, source EHR is authoritative)
9. **No encryption in local dev** -- document Phase 2 production requirements
10. **Airflow** for orchestration -- team proficient; manages layer dependency chain and hourly/daily schedules
11. **6 Decision Log entries** -- added Decision 5 (SCD Strategy) and Decision 6 (Processing Cadence) beyond prior session
