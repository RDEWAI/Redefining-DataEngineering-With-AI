## Changes Applied (DMS v1.1 alignment)

1. **Gold Layer Rewrite**: Removed all 7 dim_/fact_ star schema tables (dim_patient, dim_provider, dim_organization, dim_payer, fact_encounter, fact_condition, fact_medication). Gold layer now has 3 denormalized consumer tables only:
   - `patient_summary` (30 columns, one row per patient, reads from Silver directly)
   - `patient_clinical_history` (24 columns, one row per encounter)
   - `patient_billing_summary` (21 columns, one row per encounter with billing)
   - All Gold tables read directly from Silver (clinical.*, reference.*, billing.*) with `is_current = TRUE` for SCD2 dimensions
   - No surrogate keys in Gold -- natural keys (patient_id, encounter_id) used throughout
   - DMS reference updated from [DMS SS4.1-4.3] for the three consumer tables

2. **SCD Type 2 Expansion on clinical_patients**:
   - Added to SCD2 tracking: first_name, last_name, maiden_name, healthcare_expenses, healthcare_coverage, income
   - Updated _record_hash SHA-256 hash to include all 12 SCD2 attributes: first_name, last_name, maiden_name, address, city, state, county, zip, marital_status, healthcare_expenses, healthcare_coverage, income
   - Per [DMS SS6]

3. **Reference Tables Upgraded to SCD Type 2**:
   - reference_organizations: effective_from, effective_to, is_current, _record_hash added (hash on organization_name, address)
   - reference_providers: effective_from, effective_to, is_current, _record_hash added (hash on provider_name, specialty, organization_id)
   - reference_payers: effective_from, effective_to, is_current, _record_hash added (hash on payer_name, ownership)
   - All using Delta MERGE INTO per [DMS SS6, HLD SS4.5]

4. **ARRAY<STRUCT> Complex Types in patient_summary**:
   - `allergies ARRAY<STRUCT<description VARCHAR, severity VARCHAR>>` -- all allergies, NULL severity shown as 'Unknown'
   - `conditions ARRAY<STRUCT<snomed_code VARCHAR, description VARCHAR, onset_date DATE>>` -- active only (condition_status = ACTIVE)
   - `medications ARRAY<STRUCT<rxnorm_code VARCHAR, description VARCHAR, status VARCHAR>>` -- active only (medication_status = Active)
   - Resolves DMS Open Question #1

5. **Financial Columns Un-Dropped in Bronze-to-Silver**:
   - HEALTHCARE_EXPENSES -> healthcare_expenses DECIMAL(12,2) (was DROPPED in v1)
   - HEALTHCARE_COVERAGE -> healthcare_coverage DECIMAL(12,2) (was DROPPED in v1)
   - INCOME -> income INTEGER (was DROPPED in v1)
   - Also un-dropped: LAT -> lat DECIMAL(9,6), LON -> lon DECIMAL(9,6) per DMS SS3.1
