## Design Decisions Changed
- **Decision 10**: SDP expectations are not available in open-source Spark. Spark Expectations is the sole DQ engine. SE runs inline within each task's transformation code before the write step.
- **SDP role clarified**: SDP provides dependency resolution, parallelism, incremental processing, and streaming/materialized views. It does NOT provide DQ expectations in open-source.

## Trade-offs Accepted
- All DQ checks (including simple schema/null validations) go through SE YAML rules rather than inline decorators. Acceptable because SE's `row_dq` handles simple checks efficiently and a single framework reduces cognitive load.
