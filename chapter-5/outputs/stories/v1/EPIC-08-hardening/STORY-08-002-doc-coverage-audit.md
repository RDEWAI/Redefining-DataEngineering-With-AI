## User Story

As a Data Engineer, I want all module READMEs current and ≥ 90% line coverage enforced so that the project ships with verified documentation and test depth.

## Description

Audit each `patient_360/<dir>/README.md` against the actual contents of the directory; close any README/code drift. Confirm `pytest --cov` reports ≥ 90% line coverage on `src/patient_360/`. Add a coverage badge generated by CI.

- [ ] `patient_360/README.md`, `src/patient_360/README.md`, `airflow/configs/README.md`, `contracts/README.md`, `dq_rules/README.md`, `_infra/docker/README.md`, `_infra/cd/README.md`, `tests/integration/README.md` all exist and reflect current code [LLD §9.3]
