## Key Implementation Decisions (All Sessions)

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Pipeline Scheduling | Hourly (full Bronze+Silver+Gold) | Meets 1-hour clinical SLA [DRD §4.4]; ~33 min critical path fits in 60 min window |
| Orchestration Tool | Apache Airflow | Industry standard; team expertise; DAG maps to layer dependencies |
| Spark Version | Spark 4.0.0 + Delta Lake 4.x | Requires Java 17 + Scala 2.13; forward-looking tech strategy |
| Join Strategy | Broadcast small dims + sort-merge for facts | Dims small enough (5.7K patients, 1K providers, 10 payers); SCD2 pre-filtered with is_current=TRUE |
| Rollback Strategy | Delta RESTORE + pipeline re-run | RESTORE for instant recovery; re-run for correctness verification |
| Ingestion Framework Scope | Bronze only | 13 tasks are structurally identical; Silver/Gold have diverse logic |
| YAML Config Granularity | One file per table (13 files) | Independent modification; trivial to add new tables |
| DAG Task Generation | TaskGroup with factory | Stable task IDs; collapsible in Airflow UI; auto-generated from configs |
| Generic Ingestion Operator | SparkSubmitOperator wrapper | Keeps Airflow worker lightweight; Spark handles data processing |
| DQ Rules Integration | Convention-based by table name | No explicit DQ mappings needed; new rules auto-discovered |
| Empty-Input Behavior | Default write_empty + per-table fail override | 6 critical tables fail; 7 optional tables write empty |
