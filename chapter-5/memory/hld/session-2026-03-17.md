## Key Design Decisions in Existing HLD

1. **CDC**: Hourly Full Snapshot for all 13 Phase 1 tables — no audit timestamp columns in source to support watermark-based CDC
2. **SCD**: Type 2 on dimension tables (patients, providers, payers, organizations) using SHA-256 hash comparison + Delta MERGE INTO
3. **Storage**: Delta Lake only — mandated by infrastructure-constraints.md §2
4. **Gold tables**: 3 consumer-aligned tables (patient_summary, patient_clinical_history, patient_billing_summary) aligned to DRD §4.1 and §5.5
