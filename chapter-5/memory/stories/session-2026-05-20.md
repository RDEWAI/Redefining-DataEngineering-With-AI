## Stories Update Session — 2026-05-20 (STORY-02-001 idempotency AC)

### Trigger
User-reported runtime defect on 2026-05-20: re-running the Bronze ingestion
runner against an existing Delta location failed with
`DELTA_CREATE_TABLE_WITH_NON_EMPTY_LOCATION` after the Airflow container
recreated and reset the embedded Derby metastore. Root cause:
`replace_where_write` in `src/patient_360/utils/delta_helpers.py` called
`saveAsTable` WITHOUT `.option("path", ...)`, producing managed Delta
tables. Fix: pass `.option("path", _external_table_path(table_fqn))` so
Bronze writes are external Delta and idempotent. Fix recorded in
LLD-DEVIATIONS row 6. STORY-02-001 lacked an AC that would have caught
the defect, so the user asked us to add one.
