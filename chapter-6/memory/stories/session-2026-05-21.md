## Scope

Re-baselined STORY-02-006 (Wire Bronze TaskGroup + reconciliation_bronze into

## Trigger

LLD v1.15 §4.1 re-capped DEV `max_active_tasks` from 16 → **1** per a new
§13 Decision 12 Constraints paragraph (added 2026-05-21). The embedded Derby
Hive metastore is single-process; with `max_active_tasks=16` the second
`SparkSubmitOperator` task to start raised
`ERROR XSDB6: Another instance of Derby may have already booted the database null`
on the first DAG run, reproducing the failure on 2026-05-21.

The `bootstrap_se` task (LLD §4.2, STORY-02-006 AC5) only closes the
SE-table CREATE race — it does **not** bypass Derby's concurrent-access
limit. Both gates are needed together.
